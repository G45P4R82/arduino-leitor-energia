# Seguranca

- Nao commitar chaves ThingSpeak.
- Nao commitar senha Wi-Fi.
- Use `secrets.h` local para Write API Keys dos firmwares.
- Use `.env` local para Read API Keys do monitor.
- Gere novas chaves se uma chave aparecer em chat, log, screenshot ou repositorio.
- O SCT-013 deve ser montado sem contato eletrico com a rede e envolvendo apenas um condutor.
- Nunca deixe um transformador de corrente com carga primaria e saida aberta.
